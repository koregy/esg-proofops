## 정책과 자료 때문에 유지할 상태

- R00 §12의 사용자 채택은 프로젝트 내부 정책이며 공식 조항·법적 효력·데이터 권리의 증명이 아니다. 새 정책은 새 버전·해시·검토 이력을 통해 적용하고 과거 실행을 덮어쓰지 않는다.
- GAP-001 체크리스트 완결성 진리표는 채택됐지만 세이프하버 E/label 대응은 null/open이다. 법적 면책이나 공식 기준 충족을 자동 판정하지 않는다.
- GAP-005 열거되지 않은 하위라벨, GAP-007 사다리 빈 조합, GAP-008 공식 조항·권리, GAP-009 법적 적용, GAP-010 산업 master·적용성은 미확정 상태를 유지한다. 승인되지 않은 N/A·Scope 3 유예·crosswalk를 만들어 분모를 줄이지 않는다.
- REC-003 승인 CAPEX 계정 매핑·기간별 자료 부족, REC-004 임계값 null, REC-005/006 미완결 검색·재무 원문은 차단한다. REC-006 v2의 적시 공시 없음 출력과 불변 조회 증빙 검사는 구현됐다. HTTP 수집 연결과 실제 검증 사례 적용은 남아 있다. C5는 stage_disabled다.
- 추가 요소 P6/M4/M5/M6/G7/G8은 GAP-003에 따라 E/label/range를 바꾸지 않는다. P6의 검증된 직접 비교 결과를 확정 사실에 연결하는 경로는 구현 완료했다.
- 전체 문서 검색 완료와 부재의 의미 판단은 다르다. 전체 판독·누락 검사·검색 이력이 충족된 후에도 명시적 검토가 필요하며 기존 present/conflict를 지우지 않는다.

## 바로 이어서 수행하는 작업

1. POSCO 실제 선택 페이지 분석의 최근 결과·주장·원문 보기 동작을 최종 확인한다. 선택 범위와 판정 보류를 화면에 유지한다.
2. 새 정적 탐색 버튼 검증 정책의 타입 검사 오류를 수정하고 최신 CI·PR을 확인한다. 과거 실행의 정책·증빙을 덮어쓰지 않는다.
3. 원문 검증이 통과한 실제 주장만 보증/대사와 연결한다. 기아 통합 시험은 56개 주장 모두 보류(원문 37, 사전 분류 19)로 종료돼 보증 연결 완료가 아니다.
4. AWS 계정 인증·비용 조건이 확인되면 배포와 외부 URL 검증을 진행한다. 현재 로컬 주소만 검증됐으며 기존 Vercel 주소는 이 브랜치 배포가 아니다.

세이프하버 체크리스트 진리표와 파생 규칙팩 생성 기능, 검증된
근거를 체크리스트 항목으로 넣는 생산 경로는 구현 완료했다. 완결성이 true여도 E/label 및 법적
면책은 확정하지 않는다. GAP-005의 승인 문구와 원문 예시가 다른 조합은 기존 문자 그대로의
예시만 유지하고, 추가 조합의 하위라벨은 보류한다.
